---
name: completion-checks
description: Validate terminal-task changes and deliverables against the requested behavior.
---

Before editing, inspect the relevant source, configuration and installed tool versions. Use command output and error messages to diagnose failures rather than guessing.

After making a focused change, run the smallest relevant check, then any task-required tests. Inspect exit status and meaningful output. Reopen generated files and confirm the requested paths, formats and behavior. Preserve unrelated files and state. Distinguish successful checks, failed checks and checks that could not run.

# Improve how Memory consolidates experience

Compare the Memory plugin's supplied evidence, actual instructions and calls,
and resulting experience changes. Check whether retained statements are faithful
to observations, preserve uncertainty and provenance, distinguish tasks, and
avoid duplicating or contradicting existing experience.

Use available resource-version comparisons to identify a concrete improvement to
the plugin's consolidation procedure. Revise its authorized instructions for
retaining, qualifying or retiring observations. Memory owns the resulting
experience files. Return no change when the existing procedure already
addresses the observed issue.

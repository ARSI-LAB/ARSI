# Improve evidence-based selection guidance

Inspect the available candidate outputs, task requirements, supplied source
material, Selector inputs and trace, and the stated selection reason. Check
whether the reason refers to evidence that was actually available and whether
the compared candidates received consistent consideration. Account for changed
tasks or candidate sets when comparing plugin resource versions.

Improve the authorized selection guidance with concrete checks for overlooked
requirements, unsupported preferences, or missing evidence. Preserve applicable
anonymity constraints. A selected output is not proof that every contributing
edit worked. Use only feedback permitted by the selected evidence view, avoid
inventing a hidden rubric, and return no change when no useful revision follows.

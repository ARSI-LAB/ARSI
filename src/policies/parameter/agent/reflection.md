# Improve configuration-search guidance

Use supplied proposal, evaluation, selection and Memory evidence to improve the
next Proposer's research method. Trace an observed search problem to a specific
instruction or missing distinction. Inspect the relevant existing guidance before
editing it; return no change when the evidence does not justify a revision.

Look for repeated equivalent candidates, unsupported activation assumptions,
unproductive nearby-value scans, ignored counterexamples, redundant specialist
tasks and conclusions that confuse configuration with measured behavior. Prefer
conditional guidance explaining which evidence calls for another mechanism or
a discriminating experiment. Preserve legitimate coupled changes and uncertainty;
do not turn one failure into a permanent parameter blacklist.

Revise only the authorized Proposer guidance. Keep it compact and resolve obsolete
or contradictory advice rather than appending a transcript. Memory owns historical
lessons; cite those observations without copying winning configurations into a
universal recipe. The selector owns acceptance, and measurement records remain
immutable. Do not change the objective, workload, quality, precision, context
requirements, edit scope or expert permissions. Missing or truncated traces do
not prove that a check or specialist call never happened.

# Improve configuration-search guidance

Use proposal, evaluation, selection and available Memory evidence to improve the
next Proposer's method. Trace each revision to an observed search problem and
inspect the existing guidance first. Return no change when the evidence does not
justify an update.

Look for repeated equivalent candidates, ignored counterexamples, unsupported
assumptions and conclusions not supported by measurements. Prefer compact,
conditional instructions over universal rules inferred from a single outcome.
Preserve uncertainty and distinguish proposed changes from measured behavior.

Revise only the authorized Proposer guidance. Resolve obsolete or contradictory
advice instead of appending a transcript. Memory owns historical experience; the
selector owns acceptance. Do not change the objective, evaluation conditions,
target requirements or edit permissions. Missing or truncated evidence does not
prove that an action never happened.
